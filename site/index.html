Which image do I patch?

A quick guide before you open the app. The in-app checker reads the real partitions on your phone, so trust it over this table.

GKI (kernel 5.10+, boot header v3/v4)Select a file and patch (LKM)Patch init_boot.img if the phone launched with Android 13+, otherwise boot.img. Use the LKM that matches your KMI.

⚠ Heuristic, not a guarantee. Properties and uname can be spoofed, so the checker cross-checks several signals and marks uncertain things as RISK instead of blocking you. DarkNightSu can't force root onto a kernel that doesn't support it, and a wrong flash can brick your phone. Always back up your original boot image first — the Install screen has an Extract tool for that.
Install

Four easy steps.

Install the APK

Download the official -release.apk for your phone from Releases. Debug and CI builds are rejected by the kernel.

Check your phone

Open Install → Check my device. Read the verdict and the recommended method.

Quick start

Tap Quick start to pick the recommended method, then Next. Back up your boot image first.

Reboot & personalise

Open the manager, pick a palette, UI style and dock. Done.

FAQ

Good to know.

My phone says the bootloader is locked but I unlocked it.

Spoofing modules (integrity, uname) change what apps can read, so the checker can't fully trust it. It shows a RISK instead of blocking you, and "I know my device" lets you tell it the truth.

Do I patch boot.img on a non-GKI phone?

No. Boot-image patching (LKM) needs a GKI kernel. On non-GKI phones flash an AnyKernel3 zip with DarkNightSu built into the kernel, or build your own kernel.

Which partition: init_boot or boot?

It follows how the phone launched. Phones that launched with Android 13+ usually have an init_boot partition; older ones use boot. The checker reads the real partition list.

Why do I need a special kernel for KPM or SuSFS?

They are kernel features. The kernel must be built with CONFIG_KPM or with the SuSFS patches; the manager only controls them.

Where do I report a bug?

Use the Issues topic in the Telegram group, or open a GitHub issue. In the app, Send logs shares the report and points you to the topic.
